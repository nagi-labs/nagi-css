# Edit existing component CSS

Read [the Contract](contract.md), [definitions](definitions.md), and project
configuration. Preserve ownership, behavior and native semantics during migration.

Inspect unregistered names and STN modifiers. A popup may become a popup base;
a button's close modifier may remain. Register stable meanings as scoped roles,
not merely to clear warnings. Existing STN structure is valid and need not be
eliminated.

Update template classes and selectors together. Run lint and review grounded
fixes; uncertain meaning, required-role creation and selector
rewrites need explicit decisions. Measure through the shared analysis and keep
unknown/invalid nodes and Surface counts visible.
